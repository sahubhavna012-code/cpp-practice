# C++ Practice & OOP Fundamentals

A structured repository tracking C++ programming concepts, Object-Oriented Programming (OOP) paradigms, pointer mechanics, and foundational Data Structures.

---

## 📂 Repository Structure

```
├── 01_Basics/              # Input/Output, variables, operator fundamentals
├── 02_If_Else/             # Conditional branching & decision logic (20 problems)
├── 03_Switch_Case/         # Switch statements, menu-driven programs & logic (12 problems)
├── 04_Loops/               # Reverse, Armstrong, Fibonacci, LCM, Palindrome
├── 10_Pointers/            # Pointer arithmetic, class operations via pointers
├── 17_OOP/                 # Classes, Constructors, Destructors, Overloading, Friend Functions
└── 21_Stack/               # Stack applications (String Reversal, Postfix Evaluation)
```

---

## 💻 Key Topics Covered

### 1. Object-Oriented Programming (`17_OOP/`)
- **Classes & Objects**: Encapsulation, object instantiation, member functions.
- **Constructors & Destructors**: Default, parameterized, and copy constructors with cleanup logic.
- **Polymorphism**:
  - *Function Overloading*: Math operations, calculator functions, and custom parameters.
  - *Operator Overloading*: Overloading operators for custom classes.
  - *Function Overriding*: Inheritance-based function overrides and employee objects.
- **Friend Functions**: Non-member access to private class data.

### 2. Pointers & Memory (`10_Pointers/`)
- Pointer operations, memory references, and object access via pointers.

### 3. Core Logic & Data Structures
- **Control Flow**: Complex conditionals, leap years, character classification, quadratic roots.
- **Stack Operations (`21_Stack/`)**: Evaluates postfix expressions and reverses strings using stacks.
